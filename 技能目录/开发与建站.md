## 195 · GitHub 仓库不用自己翻

代码都在 GitHub 上，找个文件、看个仓库要登进去慢慢点。
Muse 能搜、看你的 GitHub 仓库。你说想找什么功能、哪个文件，它帮你定位，不用自己一层层翻。

**操作示例**

1. 帮我在仓库里找一下管登录的那部分；
2. 这个仓库最近改了什么？
3. 帮我看看这个项目是做什么的。

## 196 · Vercel 网站部署盯着

网站部署失败了、线上报错了，自己登后台看日志看半天。
Muse 能看你 Vercel 的项目和部署，读构建和运行日志，帮你找失败原因。你问，它给你哪一步出了问题。

**操作示例**

1. 我这个网站最新部署成功了吗？
2. 部署失败是什么原因？帮我看日志；
3. 线上这个报错是怎么回事？

## 197 · Lovable 说一句话做网站

有个想法想做个小网站，不会写代码，外包又太贵。
Muse 连上 Lovable 之后，你把想法说清楚，它帮你把网站做出来、改页面、发布。你负责说想要什么，它负责搭。

**操作示例**

1. 帮我做一个产品介绍的小网站；
2. 把首页这个标题改大一点；
3. 帮我把这个网站发布出去。

## 198 · Replit 在线写应用

想做个小工具、小应用，没环境、不会配，想法就放下了。
Muse 能在 Replit 里读、建、改、发布应用。你把要做的东西说清楚，它帮你把第一版搭出来。

**操作示例**

1. 帮我做一个简单的记账小工具；
2. 把这个应用这个功能改一下；
3. 帮我把这个应用发出去，给我链接。

## 199 · Figma 设计稿看懂再开发

设计师给了 Figma 稿，间距、组件、颜色自己量半天。
Muse 能读 Figma 的组件、间距和设计规范，帮你把设计稿变成开发能用的信息。你不用自己一层层量。

**操作示例**

1. 这个设计稿的按钮有几种状态？
2. 帮我看看这个页面的间距规范；
3. 把这个组件的样式信息给我。

## 200 · Canva 做图不用学 PS

发帖要配图、做个海报，不会设计软件，找人做又慢。
Muse 连上 Canva 之后，能帮你做设计、生成图、去背景、套品牌模板。你说要什么尺寸、什么风格，它给你出图。

**操作示例**

1. 帮我做一张发小红书的封面图；
2. 把这张图的背景去掉；
3. 按我这个模板帮我做一张海报。

## 201 · 自己造一个新技能

有个重复的活，每次都要跟 Muse 说一遍同样的要求，太啰嗦。
Muse 能帮你把一套做法存成你自己的技能：步骤、格式、注意事项都记好。下次一句话，它就按你定的规矩来。

**操作示例**

1. 把我这个日报格式存成一个技能；
2. 以后每天按这个格式给我汇总；
3. 把这个技能改一下，加上这一条。
