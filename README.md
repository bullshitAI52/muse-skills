## 如何使用

1. **选场景**：从个人项目或下面的分类进入。
2. **看类型**：提示词可以按需修改；过程记录用于参考，不应当作完整安装说明。
3. **小范围测试**：先确认当前 Muse 环境支持所需工具、授权和定时能力。
4. **核对结果**：检查原始链接、输出和任务状态，不把“已安排”的文字当成任务确实运行的证据。

## 安全与使用边界

- 不上传密码、Cookie、验证码、API 密钥或私人分享链接。登录使用可信的官方授权或安全输入。
- 涉及付款、发消息、删除资料、提交申请等操作，应先核对权限、内容和影响。
- 访问网站时遵守其规则，不绕过登录、验证码和访问限制；请求失败应降低频率或停止重试。
- 医疗、财务、法律类条目仅作资料整理思路，不能代替专业判断。
